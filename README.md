## 作品集定位

这份作品集面向机器人 / AI 产品运营岗位，重点展示以下能力：

- 用户与场景研究：识别使用者、购买者、决策链和替代方案；

## Featured case｜Roborock 东南亚 GTM

**研究问题：** 在女佣和钟点保洁普遍存在的新加坡市场，高端清洁机器人应该如何建立购买理由？

**核心判断：** Roborock 不应承诺“替代女佣”，而应定位为高频日常维护工具——机器人负责每日地面清洁，人继续承担照护、整理、厨房和深度清洁。

**本人完成：**

- 新加坡家庭清洁场景、替代方案与购买顾虑研究；
- Roborock、Dreame、Ecovacs、Narwal 四品牌竞品矩阵；
- Saros / Qrevo / Q7 产品梯度与客户价值翻译；
- 销售 FAQ、渠道与售后信任体系；
- 新加坡 90 天验证方案与东南亚市场进入顺序。

## 工作方法

```text
Research → Value → Action → Learning
理解用户 → 翻译产品 → 设计运营 → 建立验证
```

1. 明确用户、任务与当前替代方案；
2. 将功能翻译为使用证据和用户收益；
3. 设计获取、激活、使用、反馈与留存触点；
4. 用事件、指标和复盘周期推动产品与运营决策。

- Roborock 为独立桌面研究，客户案例与 90 天试点是建议方案，并非品牌委托或已验证商业结果；
- Hongbi、SomniTune 为公开原型，测试人数和验证动作均以“计划”描述；
- NavKaki 的团队季军与本人职责来自真实经历，公开页面为基于公开研究的复盘重构；
- Nutrasumma 数据来自项目材料和周度台账，回复率口径为“收到回复的已触达对象 ÷ 已完成触达对象”；
- 未虚构产品上线、用户规模或销售数据。
