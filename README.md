# Grace Tang — Product Operations Portfolio

产品运营作品集，重点展示 Roborock 新加坡与东南亚 GTM 主案例，以及 Hongbi、SomniTune、NavKaki 和 Nutrasumma 项目证据。

## Evidence policy

- Roborock 为独立桌面研究，策略、客户案例与 90 天试点均为建议方案，非品牌委托或已验证商业结果。
- Hongbi、SomniTune 为公开原型；测试人数和验证动作均以“计划”描述。
- NavKaki 公开页面为复盘重构，团队比赛获奖与本人职责来自真实经历。
- Nutrasumma 数据来自项目材料与周度台账口径。
